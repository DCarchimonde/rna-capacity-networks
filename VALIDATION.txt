RELEASE VALIDATION - 23 OCTOBER 2026

The 43-step computational workflow was executed from the supplied count
projections. All stages completed successfully after correcting the numerical
category-ordering issue described below. Raw GEO extraction was not repeated.

  Runtime columns are excluded from numerical equality checks.

- All 2,048 paired-permutation p-values and rejection decisions match exactly.
- The synthetic evaluation count arrays regenerate exactly from their seeds.
- All 12 regenerated PDFs render identically to the manuscript figures at 110 dpi.
- All five C++ kernels compile to byte-identical libraries before and after formatting.
- The unchanged third-party CS-CORE source and licence are retained.

Independent implementation checks

- 60 exact occupancy-identity checks and 48 sparse-bound checks.
- 973 LP deletion-compensation checks and bivariate integration checks.
- 128 count, component and manuscript-result consistency checks.

Permutation reproducibility correction
Recomputing component values produced differences of at most 1.735e-18 in the
matched-moment lookup. Grouping directly on those floating-point values changed
category ordering and hence the seeded permutation stream. The release fixes
the original integer category labels, recalculates the component values, and
checks/canonicalises numerical identities within 64 machine epsilons of their
scale. The observed and permuted statistics use the same canonical values.
The original seeds, evaluation cells and statistics are retained. All reported
p-values and decisions reproduce. See REPRODUCE.txt and the grouping input record.

The reused development-reference tables now use the final pipeline schema,
including availability/status fields. Their existing scientific values and
arrays were checked before replacement. Original runtime measurements remain
as reported; newly measured runtimes are not substituted into the paper.

The full numerical comparison and workflow record are provided in
review/reproduction_validation.json. These are computational checks, not
additional external biological validation.
